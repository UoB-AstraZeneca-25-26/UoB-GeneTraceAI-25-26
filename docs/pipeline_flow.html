STAGE 1 RNA z-scores — Robust Lineage Conditioning + Stouffer Combination 23,977,580 rows · 16,060 genes · 1,493 lines
Robust z-score within lineage (median / MAD)

Each source is z-scored within its lineage group using median and normalised MAD. Resistant to the outliers (skew −4.54, excess kurtosis ≈78) typical in RNA expression. Lines with fewer than 5 peers in a lineage (MIN_PEERS = 5) receive NaN and are excluded from downstream combination for that source.

z_ig = ( x_ig − median_L ) / max( MAD_L × 1.4826 , 0.384 )

MAD floor 0.384 calibrated against shared transcriptomics notebook · MIN_PEERS = 5

Limitation — silence-floor interaction

When a gene is silent across a lineage, MAD → 0 and gets floored to 0.384. Any small expression above the lineage median then produces a large z-score (e.g., 0.5 log₂ units above median → z = 1.3). Genes that are genuinely unexpressed in a tissue type can appear artificially variable. This inflates confidence for pairs where the gene is biologically off; it is the same signal-noise confound that MAD-based outlier detection was designed to suppress, not eliminate.

Stouffer combination across sources

Sources weighted by square-root panel size. The shrinkage correction multiplies z_raw by √(n_observed/n_total) < 1, pulling sparse-source pairs toward zero beyond what the Stouffer weights already capture. At n_observed = 1 of n_total = 3: z_t = z_raw × √(1/3) ≈ 0.577 × z_raw. This is an additional epistemic discount on top of the standard weighted combination; it lacks a formal derivation but is a documented conservative design choice.

z_raw = ∑ᵢ ( √nᵢ · zᵢ ) / √ ∑ᵢ nᵢ (standard weighted Stouffer)
z_t = z_raw × √(n_observed / n_total) ∈ [0, 1) for sparse pairs

Note: √(n_obs/n_tot) is computed as dividing by √(n_tot/n_obs). The direction is confirmed: z_t < z_raw when n_obs < n_tot — shrinks, not amplifies.

James–Stein shrinkage (corrected: λ decreases with n)
λ = K / (n + K) K = 30 λ = 0.86 at n=5 · 0.50 at n=30 · 0.09 at n=300
ρ̂_g = λ · ρ_prior + (1−λ) · ρ_raw ρ_prior = 0.373
Protein-within-RNA residual — which ρ is used

The ρ_g used here is the per-gene Pearson correlation between protein z-score and RNA z-score across shared cell lines — the RNA–protein expression correlation. It is not the platform-agreement ρ (ProCAN vs CCLE) from the tier step. The two quantities happen to share the same prior (0.373 = median of both), but they are distinct: the platform ρ measures measurement reproducibility; the RNA–protein ρ measures biological covariation between layers. Using the wrong one would remove a biologically irrelevant fraction of protein variance instead of the RNA-shared component.

z_prot_resid = z_prot − ρ̂_g(RNA–prot) · z_rna

The residuals are then re-standardised by global robust z-score across all lines. The standard deviation of z_prot_resid is approximately √(1−ρ²) ≈ 0.93 before re-standardisation; the robust-z step brings it back to unit scale.

STAGE 3 Alteration Scoring — Mutations, Fusions, Copy-Number 632K + 144K + 117K pairs
Mutations — Hill functions + Noisy-OR + clip
hill(x, p0, k) = xᴾ / (xᴾ + p0ᴾ)
p_base = 1−(1−p_VEP)(1−p_path)(1−p_burden)
p_mut = clip( p_base + 0.15·driver_flag , 1.0 )
Limitation — p_burden / gene-length confound

p_burden counts variants per (gene, line), capped at 5. Long genes accumulate more neutral variants under a neutral mutation rate: TTN, MUC16, OBSCN top mutation-frequency lists regardless of selection. Without normalisation for coding length and trinucleotide context (MutSigCV-style), p_burden is partly a proxy for gene length. Hypermutant lines (MSI, POLE-mutant) will saturate p_burden across most genes, enriching those lines in HIGH tier for reasons unrelated to any specific gene.

Limitation — Noisy-OR channel dependence

ClinVar/COSMIC pathogenicity (p_path) is partially derived from consequence class (p_VEP). The channels are not independent; Noisy-OR inflates p_base upward. Mutual information between channels has not been measured.

632,000mutation pairs
Fusions — Binary × Confidence

Score is 0 when no fusion is detected. An unassayed line and an assayed fusion-negative line are indistinguishable.

p_fusion = conf_weight × 1[fusion detected]
144,000fusion pairs
CNA — Absolute CN Thresholds
amp: TOTAL_CN > 2.5 AND role ∈ {oncogene, both}
del: TOTAL_CN < 1.5 AND role ∈ {tsg, both}
Limitation — no ploidy correction

Fixed absolute-CN thresholds penalise aneuploid lines: a tetraploid (ploidy=4) needs CN > 2.5 to be called amplified, which is actually a relative deletion. Correction requires subtracting expected CN (proportional to ploidy) before thresholding. Ploidy data not currently in the warehouse.

Limitation — measurement flag absent

A line never profiled for CNA receives has_cna_alteration = False (left-join fill). Unassayed and assayed-negative are indistinguishable throughout the pipeline.

STAGE 4 Core Score — Orthogonal Combination + Per-Pair Fallback ~24M rows · 16,050 genes · 1,493 lines (all RNA-profiled)
Step 1 — Within-lineage RNA percentile → z-score (probit)
rna_pct = rank(rna_z, within lineage) / n ∈ (0, 1)
rna_pct_z = Φ¹( clip(rna_pct, 0.001, 0.999) ) ∈ (−∞, +∞) mean≈0, sd≈1
Step 2 — Protein residuals → global robust z-score
prot_resid_z = ( z_prot_resid − median_global ) / MAD_global × 1.4826

Both rna_pct_z and prot_resid_z are on the same standard normal scale. The combination is commensurable.

Step 3 — Orthogonal combination (RNA + Protein, n_layers = 2)
W_RNA = √2 = 1.414 (2 independent RNA sources) W_PROT = √1.45 = 1.204 (n_eff at ρ=0.373)
core_z = ( W_RNA · rna_pct_z + W_PROT · prot_resid_z ) / √3.45
core_score = Φ(core_z) ∈ [0, 1]

W_RNA = √2 is provisional pending T3 covariance measurement. sd(prot_resid_z) = 1 after robust-z re-standardisation; the √(1−ρ²) ≈ 0.93 rescaling is handled by that step.

Per-pair fallback — protein-free lines (n_layers = 1)

Previously, 1,073 RNA-profiled lines had no protein coverage and received no score for the 10,871 shared genes, losing 48.6% of all RNA pairs. The per-pair fallback recovers these lines: for each protein-capable gene at a line without protein data, the score is the RNA percentile directly (the norm.ppf → norm.cdf round-trip returns the original percentile). The fallback uses the same formula as RNA-only genes.

core_score = Φ(Φ¹(rna_pct)) = rna_pct [n_layers = 1 fallback, protein-free lines]

These lines have n_layers = 1 even though the gene has protein data — the flag records data availability for that specific pair, not for the gene in general.

Finding — expression rank and alteration are near-orthogonal (1.17× enrichment)

Expected HIGH under independence = 228K × 19.9% = 45,400. Observed = 53,000. Enrichment = 1.17×. The tiers cross two near-independent variables; HIGH implies joint evidence but delivers only a 17% enrichment over chance. The near-orthogonality is itself a reportable finding: genomic alteration and transcriptional upregulation are largely independent signals in this DepMap corpus. Use tiers as a filtering convention, not as a probabilistic claim.

Architecture gap — no measurement flag / abstention

None of the 12 fields records whether a measurement was taken. Unassayed and assayed-negative lines are indistinguishable for all three alteration types. A __measured boolean per alteration type, or a Kleene three-valued output, is the minimum needed to distinguish “negative” from “unknown.”

Top-30 cell lines. ACH ID · name · score · tier. Accepts symbol or ENSG.

Full metadata: score, tier, rank, n_layers, alteration fields, lineage, disease, sex, age, growth pattern.
genes A B [C …]
joint = min(score_A, score_B, …)
Co-selection. Gödel t-norm (weakest-link AND). Floor = 0.50 before ranking.
exclude A B
selectivity = score_A × (1 − score_B)
Selectivity query. Product form — Łukasiewicz-style, different from the min() operator used in genes. Consistent with different semantics (exclusion vs conjunction).
Limitation — min vs product operator inconsistency

The genes command uses min() (Gödel t-norm: zero if either gene is zero). The exclude command uses a product form (multiplicative penalty). These are not parallel: a gene scoring 0.5 contributes differently to a conjunction than to an exclusion. The asymmetry is a documented design choice, not a bug, but users should not expect the score scales to be comparable across commands.
