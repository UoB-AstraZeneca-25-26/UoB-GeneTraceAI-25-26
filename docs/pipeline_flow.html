Stage 1 — Scale standardisation (per source)
RNA: auto-detected log transform
maybe_log(v): if max(v) > 25 or min(v) < -10: → log₂(clip(v, 0) + 1) else: → v unchanged
DepMap arrives log₂ — no change. HPA nTPM (linear, median ≈ 12) and GEO warehouse values (linear, median ≈ 489) are both transformed. Scale detected per source, not pooled.
Protein: already on log scale
ProCAN: log₂ intensity, range [-5, +15] CCLE: log-ratio, range [-11, +5] → no transform applied
Offset between platforms (~3.5 units) is irrelevant — the within-lineage z-score subtracts each source's own median, so the absolute offset cancels in the next stage.
Stage 2 — Lineage-conditioned robust z-score (within each source × lineage stratum)
robust_z_matrix — applied per lineage group
for each (source, lineage): med = nanmedian(X, axis=lines) # per gene MAD = nanmedian(|X − med|) × 1.4826 MAD = max(MAD, 0.384) # MAD_FLOOR z = (X − med) / MAD z[n_valid < 5] = NaN # MIN_PEERS
30 lineages across 1,840 model_ids. MAD_FLOOR = 0.384 prevents pathological z-scores when all lines in a lineage express the gene at the same level. MIN_PEERS = 5 suppresses estimates from micro-lineages.
Same function, same parameters
ProCAN: 30 lineages × 8,186 genes CCLE: 30 lineages × 11,715 genes MAD_FLOOR = 0.384 (identical) MIN_PEERS = 5 (identical)
Protein z-scores are within-lineage too. A breast cancer line with z = +2 means it has 2.7× the lineage-median deviation above the breast-lineage median for that protein — tissue bias removed.

ρ = 0.812
Measured on shared genes. High — same underlying biology, similar sequencing protocols. Kish n_eff = 2/(1+0.812) ≈ 1.10 for this pair alone; GEO adds coverage but at lower ρ.
ProCAN ↔ CCLE (Prot–Prot)
ρ = 0.373
Median per-protein Spearman, 291 shared lines (test_run_proteomics_platform_overlap.py). Platform effect (DIA-MS vs TMT) is real. Kish n_eff = 2/(1+0.373) ≈ 1.45.
RNA ↔ Protein (cross-layer)
ρ ≈ 0.37–0.46
Literature range for cell lines. Per-gene ρ estimated from overlap; shrunk toward 0.373 (James–Stein) when n_overlap < 30. Orthogonalisation corrects for this.
Stage 5 — Orthogonal RNA-protein combination (Cell 7i)
Three-step orthogonal combination → core_z
STEP 1
Per-gene ρ estimation
For each gene with both layers: r = Pearson(rna_z, prot_z) over overlapping lines λ = 30 / (n_overlap + 30) ρ_g = λ·0.373 + (1-λ)·r Prior: ρ₀ = 0.373
STEP 2
Partial residualisation
prot_resid = prot_z − ρ_g × rna_z prot_resid_z = prot_resid / √(1 − ρ_g²) → unique protein signal (post-transcriptional)
STEP 3
Weighted combination
core_z = (W_RNA × rna_z + W_PROT × prot_resid_z) / √(W_RNA² + W_PROT²) core_score = Φ(core_z)

Information audit — gains and losses per stage

Every transformation preserves some information and discards some. This table makes that explicit so each trade-off is a deliberate design decision, not a silent side-effect.

Stage Layer What you gain What you lose Statistical justification
Scale standardisation All sources
✓ Cross-platform comparability ✓ Single consistent log₂ space
✗ Absolute expression magnitude (partial) ⚠ log₂(0+1)=0 conflates zero-expression with missing data
Log transforms compress heteroscedasticity in count data and bring variance closer to constant across expression levels (Durbin 2002). The +1 pseudocount is standard but loses the zero-inflation structure.
Lineage z-score RNA + Protein
✓ Tissue-of-origin bias removed ✓ "High relative to peers" is meaningful ✓ Robust to outliers (MAD vs SD) ✓ Platform offset cancels (median subtracted)
✗ Absolute expression level gone ✗ Cross-lineage comparisons invalid ⚠ Small lineages (n=5) produce noisy z-scores despite floor ⚠ Lineage label errors propagate silently
Within-lineage normalisation is standard in CRISPR fitness screens (Behan 2019). MAD is 4.5× more efficient than SD for contaminated Gaussian data (Hampel 1974). MAD_FLOOR = 0.384 = 1/(2√2·Φ⁻¹(0.75)) matches the calibrated threshold from the shared notebook.
Stouffer combination (RNA) RNA only
✓ 1,501 model_ids scored (vs 1,479 DepMap-only) ✓ Source reliability encoded in √n weights ✓ Shrinkage penalises single-source uncertainty ✓ n_sources column tracks evidence depth
✗ Kish correction underestimates true redundancy for 3 correlated sources ⚠ DepMap–HPA ρ=0.812 → only 1.1 independent observations for that pair ⚠ GEO probes are microarray — different noise model than RNA-seq
Stouffer's method (fixed-effects meta-analysis) is BLUE under normality when weights equal √n (Hedges & Olkin 1985). The Kish design effect correction, n_eff = k/(1+(k-1)·ρ̄), adjusts for between-source correlation but assumes uniform pairwise ρ, which is a simplification here.
Stouffer combination (Protein) Protein only
✓ 1,014 model_ids scored (vs 375 CCLE-only) ✓ 21% of (gene, line) pairs have two-platform confirmation
✗ 79% of pairs are single-platform — penalised by √2 shrinkage ⚠ ProCAN–CCLE ρ=0.373 means only 1.45 effective observations even at best ⚠ Isoform ambiguity: 232 UniProt accessions unmappable to ENSG
Platform ρ=0.373 is in the "merge with caution" range per the internal test. The Stouffer shrinkage factor √(2/1)=1.41 reduces single-platform z-scores by ~30%, which is the correct conservative approach under uncertainty about platform reproducibility.
Per-gene ρ estimation Cross-layer
✓ Gene-specific correlation accounted for ✓ James–Stein shrinkage prevents overfitting sparse overlaps
✗ ρ estimated with error (Pearson on ≤375 lines for CCLE genes) ⚠ RNA-only genes use prior ρ=0.373 — no empirical estimate possible ⚠ ρ assumed stationary across lineages
James–Stein shrinkage λ = n_min/(n+n_min) with n_min=30 is a standard empirical Bayes regularisation. Genes with n_overlap ≥ 30 receive <50% shrinkage; genes below receive majority-prior scores. This is the same philosophy as MAD_FLOOR — calibrate, don't trust sparse estimates.
Orthogonal combination Cross-layer
✓ Double-counting of shared RNA-protein variance eliminated ✓ Protein residual captures post-transcriptional regulation ✓ Kish-weighted combination is the BLUE under ρ-corrected assumptions ✓ RNA-protein contradictions reduce core_score (correct)
✗ At ρ_g → 1, protein contributes nothing (prot_resid_z ≈ 0) ⚠ ρ assumed linear; non-linear RNA–protein dependence not captured ⚠ Cross-lineage ρ variation assumed zero
The partial correlation approach is equivalent to hierarchical regression: first fit RNA, then add protein residual. This is the canonical way to combine correlated predictors in a latent variable model. The information added by protein = (1−ρ²) × Var(prot_z) — quantifiable, not assumed.
Φ(core_z) transformation Final
✓ Score in (0, 1) — compatible with downstream pipeline ✓ Magnitude preserved: z=2 → 0.977, z=4 → 0.99997 ✓ Interpretable: probability under standard normal
✗ Tail compression: z=3 vs z=5 nearly identical (0.9987 vs 0.9999) ⚠ core_z normality assumed — violated by heavy-tailed protein distributions
Φ(z) is a monotone bijection — it preserves all ranking information that z-scores contain. Unlike rank(pct=True), distances are preserved in the middle of the distribution where most genes live. The tail compression is a feature for high-confidence callers: extreme outliers (z>3) all score near 1.0, which is appropriate for a "very likely elevated" signal.
