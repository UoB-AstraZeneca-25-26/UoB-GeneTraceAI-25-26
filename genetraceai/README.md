# GeneTraceAI

Self-contained React UI. Only depends on React.

## Run locally
    npm install
    npm run dev

Then open the URL Vite prints (default http://localhost:5173).

## Build for production
    npm run build
    npm run preview

## Notes
- All styling and fonts are inlined in src/App.jsx — no Tailwind or CSS setup needed.
- The data in src/App.jsx (the GENES object) is illustrative demo data.
  Replace it, or fetch from your API, to run on real scores.
