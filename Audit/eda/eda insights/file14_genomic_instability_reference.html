Key identifier

ModelID contains ACH- IDs throughout (3,021/3,021). Joins directly to File 9 (sample_info) on DepMap_ID, and via File 8 (OmicsProfiles) to expression data. No CVCL accessions present — CVCL bridge must go via File 9 → File 7.

Filtering strategy

3,021 rows represent multiple sequencing runs per cell line. IsDefaultEntryForModel == "Yes" reduces to 1,955 unique cell lines, one row each. Always apply this filter before any join or analysis.

Role in CellLineFinder

These are contextual flags for the evidence card, not inputs to the expression-based confidence score. Useful for:

  • Flagging MSI-high lines where genomic instability may confound target expression
  • Flagging high ploidy or WGD lines where copy number affects apparent expression levels
  • Flagging high CIN lines as potentially less reproducible models

Feed into the AI rationale layer (trade-off flags) rather than the statistical scoring model.

Known pitfalls

  • Always filter IsDefaultEntryForModel == "Yes" before any join — raw file has 3,021 rows for 1,955 cell lines
  • WGD is float (0.0/1.0) not boolean — cast explicitly
  • Aneuploidy is float (integer values) — cast to int
  • No CVCL accessions — bridge to CVCL golden key via File 9 (DepMap_ID → cell_line_name) → File 7
  • 333 null LoHFraction rows after filtering are genuine missing data, not QC failures
  • File named "Signatures" but contains no mutational or pathway signatures
