Critical Finding — Row IDs are Profile IDs, Not Cell Line IDs
⚠ Critical
Row indices are PR- Profile IDs, not ACH- cell line IDs. The expression matrix cannot be directly joined to sample_info or Cellosaurus without first resolving PR- → ACH- via File 8 (OmicsProfiles). Zero rows matched sample_info in a direct join — this confirmed the mismatch.

This means the file is the per-profile version of the expression data, not the per-cell-line version. Each row represents one sequencing run, not one cell line. The bridge through File 8 is mandatory before any downstream use.

Extraction pattern confirmed working:

import re def extract_ensembl(col_name): match = re.search(r'(ENSG\d+)', col_name) return match.group(1) if match else col_name # fallback for bare Ensembl IDs # Tests extract_ensembl('TSPAN6 (ENSG00000000003)') # → ENSG00000000003 ✓ extract_ensembl('ENSG00000288721') # → ENSG00000288721 ✓ extract_ensembl('EGFR (ENSG00000146648)') # → ENSG00000146648 ✓
⚠ Data Dictionary Discrepancy
The data dictionary described column headers as SYMBOL (ENTREZ_ID) e.g. EGFR (1956). The actual file uses SYMBOL (ENSG...). Always use the actual column format — not the data dictionary description — when writing parsing code.

16 cell lines each have 2 RNA profiles. This is not a data error — it occurs when a cell line is re-sequenced, measured under different conditions, or contributed by different labs. However it requires an explicit team decision before preprocessing.

⚠ Coverage Gap
1,479 cell lines have RNA data. Sample_info contains 1,840 cell lines. This means 361 cell lines have metadata but no expression measurements. These will appear in the system with mutation/fusion data potentially available but no expression confidence score. The UI must handle this gracefully — not crash or return empty results.
8
Team Decision Points
⚡ Duplicate RNA profiles

16 cell lines have 2 RNA profiles each. Options: take the mean, keep most recent, or keep highest coverage. Must be decided and documented before writing the join code.

⚡ 422 symbol-less genes

422 columns have bare Ensembl IDs with no gene symbol. Likely novel or uncharacterised. Decision: keep with Ensembl-only label, or drop from the gene universe entirely.

⚡ Protein-coding filter

Team agreed to filter to protein-coding genes (~20,000). The current matrix has 53,961 columns including non-coding. Apply HGNC gene_biotype filter after ID mapping.

⚡ 361 cell lines with no RNA

In sample_info but not in expression data. System must handle queries for these gracefully — show mutation/fusion evidence if available but flag absent expression data clearly.
