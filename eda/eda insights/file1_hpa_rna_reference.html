Integration Notes

  • Use nTPM as the expression value. Apply log2(nTPM + 1) at the integration stage — values are not pre-transformed.
  • DepMap expression (File 2) is already log2(TPM+1) transformed — do not transform again.
  • Normalise cell line names before CVCL join: uppercase, strip hyphens and spaces.
  • Ensembl ID is in the Gene column — use this as the golden key, not Gene name.
  • After CVCL join, log any unmapped cell lines — never silently drop.

Pitfalls

  • File is tab-separated. Reading with default comma separator produces a single-column dataframe with 5 rows. Always use sep="\t".
  • Do not use TPM or pTPM for cross-source integration — use nTPM only.
  • nTPM is NOT log-transformed. Do not skip the log2(nTPM+1) step at integration.
  • Cell line names use hyphens (A-431 not A431). Normalise before any join.
