HeLa family — critical finding

1,393 entries contain "HeLa" — these are NOT synonyms for one cell line. Each engineered variant (HeLa EGFR KO, HeLa S3, HeLa Kyoto etc.) has its own distinct CVCL accession. Never collapse all HeLa names to CVCL_0030.

Critical finding — row IDs

Row indices are PR- Profile IDs, not ACH- cell line IDs. A direct join to sample_info returns zero matches. Must bridge via File 8 (OmicsProfiles) using ProfileID → ModelID before any downstream use.

Column header format

Columns use Ensembl IDs, not Entrez IDs as the data dictionary stated. Format is SYMBOL (ENSG...) — Ensembl is already embedded. No conversion needed, just extract with regex.

Extraction pattern confirmed working:

import re
def extract_ensembl(col_name):
    match = re.search(r'(ENSG\d+)', col_name)
    return match.group(1) if match else col_name

Transformation state

Max 17.78 and median 0.014 confirm log2(TPM+1). Do NOT transform again — doing so corrupts values silently.

Missing vs zeros

No NaN values exist. Zero values (49.8%) are genuine zero expression — the gene was measured and found unexpressed. This is different from proteomics where missing means below detection limit. Do not impute zeros here.

Entity relationship

The full DepMap ID hierarchy is:

CVCL_xxxx (Cellosaurus golden key)
    → ACH-000001 (DepMap cell line ID — ModelID in this file)
        → MC-001131 (ModelCondition — experimental condition)
            → PR-AdBjpG (ProfileID — one row in expression matrix)

Key finding — WES has more coverage than RNA

1,860 cell lines have WES (mutation) profiles but only 1,479 have RNA profiles. Some cell lines will have mutation/fusion flags available in your system but no expression confidence score. Handle this gracefully in the UI and confidence scoring logic.

Using this file as the bridge

# Filter to RNA profiles only
rna_profiles = profiles[profiles['Datatype'] == 'rna'][['ProfileID', 'ModelID']]
print("RNA profiles:", len(rna_profiles))
print("Unique ACH IDs:", rna_profiles['ModelID'].nunique())

# Check for duplicates — cell lines with more than one RNA profile
dupes = rna_profiles['ModelID'].value_counts()
print(dupes[dupes > 1])
# Result: 16 cell lines have 2 RNA profiles each

WESKit column

The WESKit column is 51.4% missing. It refers to the sequencing kit used for WES profiles. Not needed for preprocessing — note and move on.

Why this file matters

  • Without this file, File 2 (expression) is not joinable to any cell line metadata
  • It also tells you which cell lines have WES data for mutation flagging even if they lack RNA
  • ModelCondition (MC- format) is the intermediate ID between cell line and profile — useful for understanding why duplicates exist
